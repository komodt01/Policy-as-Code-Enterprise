# Contributing to Policy-as-Code Enterprise Framework

## Overview
This project demonstrates enterprise-grade cloud governance using Policy-as-Code principles. Contributions should align with enterprise architecture best practices and maintain the educational/demonstration focus.

## Development Environment
- Use WSL or Linux for development
- Terraform >= 1.5 required
- AWS CLI v2 recommended
- All code should include appropriate fictional data disclaimers

## Pull Request Process
1. Create feature branch from main
2. Update documentation for any changes
3. Test changes in demo mode
4. Submit PR with detailed description
5. Ensure all automated checks pass

## Code Standards
- Follow Terraform best practices
- Include comprehensive variable validation
- Add appropriate tags and documentation
- Test in demo mode before submission

## Questions?
Open an issue for questions about architecture decisions or implementation approaches.
